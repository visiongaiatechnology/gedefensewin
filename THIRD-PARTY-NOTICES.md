# Third-Party Notices

## Go-Code

GeDefense Windows 4 enthält **keine direkten oder indirekten Third-Party-Go-Module**.

## Microsoft-Komponenten

GeDefense ruft öffentliche Betriebssystemfunktionen von Microsoft Windows auf, darunter Defender, Windows Firewall/WFP, CIM/WMI, Windows App Control, Service Control Manager sowie Win32-Prozess-, Dateisystem-, Netzwerk- und Shell-APIs. Diese Komponenten werden nicht unter AGPL relizenziert und sind nicht als Microsoft-Binärdateien in diesem Repository enthalten.

## Threat-Intelligence-Quellen

Die Anwendung lädt Feodo Tracker sowie Spamhaus DROP IPv4/IPv6 zur Laufzeit direkt von den jeweiligen Anbietern. Snapshots und abgeleitete Feed-Dateien werden nicht im Repository ausgeliefert.
